# Apple 风格 UI 全面重构

## 背景

将 `dm-inspect` 巡检系统从深色科技风（Fira Code + 绿色强调色）全面重构为 Apple 风格设计系统，支持浅色/深色双主题切换。

## 设计规范来源

项目根目录 `DESIGN.md` — Apple 风格设计系统规范，包含：

- **颜色系统**: Action Blue (#0066cc) 单强调色、浅色/深色双模式 surface
- **字体系统**: SF Pro Display / SF Pro Text、负字间距
- **圆角系统**: 18px 大圆角卡片、 pill 形状按钮
- **阴影哲学**: 仅产品图片使用阴影，UI 元素无阴影
- **排版节奏**: 低密度留白、17px 正文、600 字重标题

## 技术实现

### 主题切换机制

采用 **CSS 变量 + Tailwind `dark` class** 策略：

1. `ThemeProvider.jsx` — React Context + localStorage 持久化用户主题偏好
2. `index.css` — `:root` 定义浅色变量，`.dark` 定义深色变量
3. `tailwind.config.js` — `ds-*` token 改为引用 `var(--ds-*)`

### 颜色映射

| Token | 浅色模式 | 深色模式 |
|---|---|---|
| `--ds-bg` | #f5f5f7 (parchment) | #000000 (surface-black) |
| `--ds-surface` | #ffffff (canvas) | #272729 (surface-tile-1) |
| `--ds-surface2` | #fafafc (pearl) | #2a2a2c (surface-tile-2) |
| `--ds-text` | #1d1d1f (ink) | #ffffff (body-on-dark) |
| `--ds-muted` | #7a7a7a | #cccccc |
| `--ds-border` | #e0e0e0 (hairline) | #333333 |
| `--ds-accent` | #0066cc (Action Blue) | #2997ff (Sky Link Blue) |

### 字体栈

```
heading: "SF Pro Display", system-ui, -apple-system, sans-serif
body: "SF Pro Text", system-ui, -apple-system, sans-serif
mono: "SF Mono", SFMono-Regular, ui-monospace, monospace
```

## 后续审查与修复（simplify 技能审查）

### Hooks 规则违规修复

**问题**：`ReportList.jsx` 中 `useMemo` 被放在 `if (loading) return <Spinner />` **之后**，导致首次渲染 hooks 数量不一致，React 崩溃（error #310）。

**修复**：将所有 `useMemo` 调用移至条件 `return` 之前，并补充 `mountedRef` 在 StrictMode 双重执行下的重置逻辑。

### 内存泄漏修复

#### Toast 定时器泄漏
- `Toast.jsx` 中 `setTimeout` 未被清理。手动 dismiss 后定时器仍残留，且组件卸载时可能触发已卸载的状态更新。
- **修复**：引入 `timersRef`（Map）追踪所有定时器 ID，`dismiss()` 中主动清除，`useEffect` cleanup 中批量清理。

#### ReportList 轮询竞态
- `pendingCheckTimerRef` 使用递归 `setTimeout`（`tryFetch`），timer 引用被覆盖后旧 timer 无法清除。
- 自动轮询 interval 在 `fetchReports` 变化时重复创建/销毁。
- **修复**：
  - 扁平化轮询为最多 5 次、带 `attempts` 计数的 `doPoll`
  - 轮询 effect 依赖改为 `reports` 而非 `fetchReports`，避免 filter 切换时频繁重启
  - 所有 `fetchReports` 内部和回调中加入 `mountedRef` 守卫
  - 使用 `fetchReportsRef` 保存最新回调引用，避免 interval closure 捕获旧函数

### 冗余计算与代码复用

- `safeParse`、`getYesterday`、`formatSummary`、`reportListSummary` 四个函数在 `ProjectList` 和 `ReportList` 中重复定义。
- **修复**：统一提取到 `web/src/lib/utils.js`，两页面改为导入。
- `ReportList` 中 6 个 `selectedReport` 派生字段（`summary`、`failed_blocks`、`warnings`、`block_results`、`highlights`、`suggestions`）每次渲染都重复 `JSON.parse`。
- **修复**：全部用 `useMemo` 缓存。

### 遗留兼容性代码清理

#### index.html 硬编码 `class="dark"`
- **影响**：浅色模式用户在 JS 加载前会看到深色闪烁（FOUC）。
- **修复**：移除 `<html class="dark">`，完全由 `ThemeProvider` 在 `useEffect` 中根据 localStorage 动态切换。

#### card.jsx 默认阴影
- **影响**：Apple 设计哲学"UI 元素无阴影"，裸用 `<Card>` 会意外出现阴影。
- **修复**：从默认 class 中移除 `shadow`。

#### 内联 SVG 图标未统一
- `ScheduleList` 日志弹窗关闭按钮、5 个页面的面包屑箭头、2 个页面的警告图标均使用内联 `<svg>`。
- **修复**：全部替换为 `lucide-react` 图标组件（`X`、`ChevronRight`、`AlertTriangle`）。

## 主题切换使用方式

导航栏右上角有太阳/月亮图标按钮，点击即可在浅色/深色模式间切换，偏好自动保存到 localStorage（`theme` 键），下次访问自动恢复。
